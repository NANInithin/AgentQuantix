◈ Standard-library core

MCP server speaks JSON-RPC over stdio; the agent loop uses Python's standard-library urllib.

◈ Isolated conversion tools

Heavy stacks such as PyTorch and Transformers live in separate environments, apart from the lean core.

◈ Your agent workflow

Use an MCP-compatible client alongside the CLI, with review gates around release actions.
