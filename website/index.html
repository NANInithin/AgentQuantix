Zero-Dependency Core

MCP server speaks raw stdio JSON-RPC — no mcp package required. The agent loop uses only standard-library urllib.

Isolated Virtual Environments

Heavy converter stacks like PyTorch and Transformers install into automatic sandboxed sub-environments, keeping the core lean.

Any MCP Client

Connects out of the box to Claude Code, Codex, OpenCode and any MCP-compatible client.

NEW · v0.5.9

Engine runtime lifecycle

Flat Per-Engine Installs & In-Place Updates

Engine checkouts stay persistent and update in place — no more full reinstalls. Deleted runtime folders or foreign CMake build directories are detected and recovered automatically.

Live Build & Inference Streaming

Native CMake/ninja compiler output and model inference stream straight to stderr in real time — you watch the engine build and the model think as it happens.

Windows Short Path Handling

Native support for short build roots like AQX_WORK_ROOT=C:qx keeps MSVC nested-object paths under the limit, so deep engine builds don't fail on Windows.

Provenance & Upstream Licensing

Publications strictly preserve upstream voice licenses, NOTICE files and model-spec language options inside every published bundle.

Multimodal Research Discovery

aqx research automatically discovers and routes non-text candidates — vision, audio, multimodal, retrieval — with a --text-only flag when you want to narrow scope.
