# Vision task status

## Scope and limitations

The 0.5.6 vision.cpp route uses Acly/vision.cpp v0.3.0 at
`b766b0acc30f6706f1bfe46769635e361172ce96`. Fixtures are deterministic,
synthetic CC0 images generated by `scripts/generate_vision_fixtures.py`.
There is no real-photo validation. Depth Anything V2 is offered for relative
or ordinal depth only; no metric-depth claim is made.

## Family status

| Task | Family | Spike recommendation | Native implementation gate |
|---|---|---|---|
| Mask generation | MobileSAM | Accept | Point and box IoU >= 0.90; lower precision must stay within 0.01 IoU of baseline and pixel agreement >= 0.99 |
| Image segmentation | BiRefNet | Accept | IoU >= 0.90 and boundary F-score >= 0.80; lower precision must stay within 0.01 IoU and pixel agreement >= 0.99 |
| Depth estimation | Depth Anything V2 Small | Accept for relative depth only | Finite, non-constant baseline and near-plane output greater than far-plane output; lower precision Spearman >= 0.999 and scale-shift AbsRel <= 0.01 on three scenes |
| Inpainting | MI-GAN | Not offered | Native outputs did not beat mean-fill under PSNR/SSIM |
| Super-resolution | Real-ESRGAN anime-6B | Not offered | Native output did not beat bicubic under PSNR/SSIM |

The depth comparison fits scale and shift against the baseline and evaluates
AbsRel only where the baseline is above its fifth percentile.

Runs use Linux CPU, `--no-publish --yes`, and the lifecycle-installed
vision.cpp revision `b766b0acc30f6706f1bfe46769635e361172ce96`.

| Task / family | Source dtype | Precision | Status | Native metrics |

Recorded elapsed times sum the native CLI subprocess wall times for each
precision; they exclude conversion and Python-side metric evaluation.

The BiRefNet source contains non-F32 floating tensors, so the source-aware
policy offered F16 only and did not promote it to F32. Result manifests:

- `/home/ubuntu/spike/acceptance/vision-mobilesam-results.json`
- `/home/ubuntu/spike/acceptance/vision-birefnet-results.json`
- `/home/ubuntu/spike/acceptance/vision-depth-anything-results.json`

The converter used Python 3.12.16 in the runtime's dedicated environment, with
`torch==2.11.0+cpu`, `transformers==4.57.6`, `numpy==2.2.6` and
`gguf==0.19.0`. The result manifests record the full package set and build
fingerprint. These results validate only the fixed synthetic fixtures; they do
not establish real-photo performance, and depth remains relative/ordinal only.
